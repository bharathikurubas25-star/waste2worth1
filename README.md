# ♻️ Waste2Worth

Waste2Worth is a full-stack web application that promotes sustainable reuse by allowing users to list unused items and discover items that are available for reuse.

## 🌱 Problem Statement

Many usable items are thrown away even though they could still be useful to someone else. Waste2Worth provides a simple digital platform where users can share unused items and help reduce unnecessary waste.

## ✨ Features

- 👤 User Registration and Login
- 📦 List unused items
- 📷 Upload product images
- 🔍 Browse available items
- 📍 Add item location
- 📝 View item details
- 🤝 Send requests for available items
- 📋 Manage personal listings
- 📱 Responsive design for mobile and desktop
- 🔐 Secure password hashing
- 🗄️ MySQL database integration

## 🚀 How It Works

1. Create an account.
2. Log in to Waste2Worth.
3. List an unused item with its details and photo.
4. Other users can browse available items.
5. Interested users can send a request.
6. Items can be reused instead of being unnecessarily discarded.
